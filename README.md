# Buildlink Website

This is the first standalone React/Vite implementation of the Buildlink Construction Company Limited website.

## Important brand rule

The official Buildlink logo supplied by the client is stored at:

`src/assets/buildlink-logo.png`

Do not redraw or replace it.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org/
2. Open this project folder in VS Code.
3. Open the VS Code terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite, usually `http://localhost:5173`.

## Build for production

```bash
npm run build
```

The production files will be placed in `dist/`.

## GitHub

Create a GitHub repository called `buildlink-website`, then upload this entire project.

Do not upload `node_modules/` or `dist/`.

## Hosting

The finished project can be connected to Vercel or Netlify directly from GitHub.

## Before launch

Replace the following placeholders when official information is available:

- Founder names and biographies
- Organisation structure
- Project portfolio
- Address
- Phone
- Email
- Website/domain
- Official social media accounts

The contact form currently demonstrates the interface only. Connect it to the official Buildlink email/form service before launch.

## Images

The current construction/architecture imagery uses remote Unsplash image URLs as visual placeholders. Replace these with Buildlink's approved project/site photography when available.
